# flipsitherm-site

Landing page for FlipsiTherm – herstellerneutrale, offline-fähige Auslegung von
Schaltschrank-Heizung und -Kühlung (IEC TR 60890 / EN 61439). Kostenlos, open source.

Live: https://techflipsi.github.io/flipsitherm-site/

Statische Seite (HTML/CSS, keine Build-Pipeline). Impressum/Datenschutz nach österreichischem Recht
(MedienG, DSGVO), gehostet auf GitHub Pages.
